# Web Engineering Lab 02

## About
This project is part of my Web Engineering Lab 02. 
The main focus of this task is to create an accessible and user-friendly webpage using HTML, CSS, and JavaScript.

## Features

- Skip to main content link
- Accessible navigation menu
- Office Hours table
- Accessible SVG icons
- Send Feedback form
- Required form fields
- Email validation
- Keyboard focus styles
- Accessible radio buttons
- Responsive design
- Accessibility testing with axe DevTools and Lighthouse

## Technologies Used

- HTML5
- CSS3
- JavaScript
- VS Code
- Live Server
- axe DevTools
- Lighthouse
