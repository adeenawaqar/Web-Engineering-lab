# Web Engineering Lab 03

## Introduction
This project is created for Web Engineering Lab 03. It demonstrates basic CSS concepts using HTML and CSS.

## Objectives
- Learn CSS colors and selectors.
- Understand inline, internal, and external CSS.
- Practice text styling using CSS.
- Understand `px`, `em`, and `rem` units.
- Create a navigation bar using Flexbox.
- Design a webpage layout using header, content, and footer.
- Learn fixed positioning.
- Practice Flexbox centering.
- Understand responsive design using media queries.
- Apply hover transitions and CSS animations.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Live Server Extension

## Tasks Completed

1. **CSS Colors:** ID selectors, class selectors, and different CSS methods.
2. **Text Styling:** Text alignment and text transformation.
3. **CSS Units:** Comparison of px, em, and rem.
4. **Navigation Bar:** Logo, navigation links, and search bar.
5. **Page Layout:** Header, three content boxes, and footer.
6. **Fixed Positioning:** A fixed Love Nature box.
7. **Flexbox Centering:** Centering a child element inside its parent.
8. **Media Queries:** Changing colors according to screen width.
9. **Hover Transition:** Changing button appearance on hover.
10. **CSS Loader:** Creating a rotating loader using animation.

## How to Run the Project

1. Open the project folder in Visual Studio Code.
2. Make sure `index.html` and `style.css` are in the same folder.
3. Install the Live Server extension if it is not already installed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. View the webpage in your browser.
