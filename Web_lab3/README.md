Introduction

This project is created for Web Engineering Lab 03. It demonstrates basic CSS concepts using HTML and CSS.

Objectives

Learn CSS colors and selectors.

Understand inline, internal, and external CSS.

Practice text styling using CSS.

Understand px, em, and rem units.

Create a navigation bar using Flexbox.

Design a webpage layout using header, content, and footer.

Learn fixed positioning.

Practice Flexbox centering.

Understand responsive design using media queries.

Apply hover transitions and CSS animations.

Technologies Used

HTML5

CSS3

Visual Studio Code

Live Server Extension

Tasks Completed

CSS Colors: ID selectors, class selectors, and different CSS methods.

Text Styling: Text alignment and text transformation.

CSS Units: Comparison of px, em, and rem.

Navigation Bar: Logo, navigation links, and search bar.

Page Layout: Header, three content boxes, and footer.

Fixed Positioning: A fixed Love Nature box.

Flexbox Centering: Centering a child element inside its parent.

Media Queries: Changing colors according to screen width.

Hover Transition: Changing button appearance on hover.

CSS Loader: Creating a rotating loader using animation.

How to Run the Project

Open the project folder in Visual Studio Code.

Make sure index.html and style.css are in the same folder.

Install the Live Server extension if it is not already installed.

Right-click index.html.

Select Open with Live Server.

View the webpage in your browser.
