## Project Description

This project is part of Web Engineering Lab 01. It demonstrates the basic setup of a Node.js web project, including HTML, CSS, JavaScript, testing, ESLint, Prettier, and Git/GitHub.

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* ESLint
* Prettier
* Git and GitHub

## Commands

Run the project:

```bash
npm start
```

Run tests:

```bash
node --test
```

Check ESLint:

```bash
npm run lint
```

Check formatting:

```bash
npm run format
```

## Learning Objectives

* Understand the basic structure of a Node.js web project.
* Practice HTML, CSS, and JavaScript.
* Learn basic testing with Node.js.
* Use ESLint and Prettier for code quality and formatting.
* Learn Git and GitHub for version control.
